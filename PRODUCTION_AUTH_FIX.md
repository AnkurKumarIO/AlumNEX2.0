# Production Authentication Fix

## Problem
- Mentorship settings save works locally but fails on production with "invalid token" error
- GET requests work but POST requests fail with authentication error

## Root Cause
The JWT_SECRET environment variable on your production backend (Render.com) is either:
1. Not set (using fallback secret)
2. Set to a different value than local

This causes tokens generated by one environment to be invalid in the other.

## Solution - Update Production Environment Variables

### Step 1: Set JWT_SECRET on Render.com

1. Go to [Render.com Dashboard](https://dashboard.render.com/)
2. Select your backend service (`alumnex2-0`)
3. Go to "Environment" tab
4. Add/Update environment variable:
   ```
   Key: JWT_SECRET
   Value: alumnex_jwt_secret_2026_secure
   ```
5. Click "Save Changes"
6. Wait for service to redeploy (automatic)

### Step 2: Clear Browser Data and Re-login

After backend redeploys:
1. On production website, open browser console (F12)
2. Run: `localStorage.clear()`
3. Refresh the page
4. Login again with your credentials
5. This will generate a new token with the correct secret

### Step 3: Test Mentorship Settings

1. Go to Settings → Mentorship
2. Add/modify a slot
3. Click "Save Changes"
4. Should now save successfully ✅

## Alternative: Quick Test Without Redeployment

If you can't redeploy immediately, you can test by:
1. Logging out on production
2. Logging in again on production
3. This generates a new token using whatever secret production currently has
4. Try saving again

If it still fails, then the JWT_SECRET MUST be set on Render.com.
